FAQ

So läuft ein Spieltag mit dieser App.

Wie funktioniert das Live-Zählen?

Öffne deinen Scorer-Link (/scoreday/…) auf dem Handy am Platz. Tippe bei jedem Ballwechsel auf Punkt für den Gewinner — Spiele, Sätze, Tiebreaks und Einstand werden automatisch gezählt. Mit Spiel trägst du ein ganzes Spiel auf einmal ein, mit Rückgängig nimmst du Fehler zurück.

Wie schauen Zuschauer live zu?

Teile den Zuschauer-Link (/watchday/…) aus dem Teilen-Bereich des Spieltags. Alles aktualisiert sich automatisch in Echtzeit — die Spielkarten, der Teamstand und die Satz-/Spielsummen. Kein Konto nötig.

Was ist der Unterschied zwischen Scorer-Link und Zuschauer-Link?

Der Scorer-Link kann Ergebnisse eintragen, Doppel aufstellen und Matches zurücksetzen — behandle ihn wie einen Schlüssel und gib ihn nur der Person, die zählt. Der Zuschauer-Link ist nur zum Ansehen und kann bedenkenlos an alle geteilt werden.

Wie lege ich die Doppel-Paarungen fest?

Sobald alle Einzel beendet sind, erscheint auf der Spieltag-Seite des Scorers automatisch das Formular „Doppel-Paarungen festlegen". Spieler für jedes Doppel auswählen und auf Doppel anlegen tippen. Danach schließt sich das Formular; ein kleiner Button Doppel-Paarungen bearbeiten bleibt im Doppel-Bereich, bis das erste Doppel beginnt.

Ein Doppel läuft schon — wie ändere ich eine falsche Aufstellung?

Sobald ein Doppel gestartet ist, sind die Paarungen fixiert und der Bearbeiten-Button verschwindet. So änderst du die Namen trotzdem:

  1. Öffne dieses Doppel von der Spieltag-Seite aus (als Scorer).
  2. Tippe auf Zurücksetzen — das löscht den Spielstand (nur dieses eine Match).
  3. Zurück auf der Spieltag-Seite ist der Button Doppel-Paarungen bearbeiten wieder da. Namen korrigieren und speichern.
  4. Bereits gespielte Punkte ggf. neu eintragen.

Hinweis: Zurücksetzen löscht den Spielstand wirklich — deshalb ist das Ändern einer laufenden Paarung bewusst kein Ein-Klick-Vorgang.

Ich habe einen Punkt dem falschen Spieler gegeben — was jetzt?

Tippe auf der Match-Seite auf Rückgängig. Das nimmt die letzte Aktion zurück (Punkt oder Spiel), Schritt für Schritt, und korrigiert auch die Punkt-Statistik.

Ein Match wurde nicht live gezählt — kann ich das Endergebnis eintragen?

Ja. Auf der Spieltag-Seite des Scorers hat jede Spielkarte einen Button Ergebnis eintragen, in dem du die Satzergebnisse direkt eingibst (z. B. 6:4, 3:6, 10:7).

Was sind die Punkt-Markierungen (Ass, Winner, …)?

Nach jedem Punkt kann der Scorer optional markieren, wie er endete — Ass, Winner, unerzwungener Fehler, erzwungener Fehler oder Doppelfehler. Die Markierungen speisen die Statistik. Sie sind optional und können übersprungen werden; das Fenster schließt sich von selbst. Zuschauer sehen die Statistik, sobald das Match beendet ist.

Brauche ich ein Konto?

Nur zum Erstellen von Spieltagen. Registriere dich unter /register und nutze dann „Neuer Spieltag" in deinem Dashboard. Zählen und Zuschauen funktionieren allein über die geteilten Links.

Woher kommen die Vereinsspieler und LK-Werte?

Von der WTB-Website. Beim Erstellen eines Spieltags suchst du einen Verein, und die Spielerliste (mit Rang und LK) lädt automatisch. Die Spielerdaten werden aktualisiert, wenn sie älter als eine Woche sind; ein Admin kann die Synchronisierung auch manuell anstoßen.

FAQ

How to run a match day with this app.

How does live scoring work?

Open your scorer link (/scoreday/…) on the phone at the court. On each match, tap Point for whoever won the rally — games, sets, tiebreaks and deuce are handled automatically. Use Game to award a whole game at once, and Undo to take back mistakes.

How do spectators watch live?

Share the spectator link (/watchday/…) from the match day's Share section. Everything updates automatically in real time — the match cards, the team score and the sets/games totals. No account needed.

What's the difference between the scorer link and the spectator link?

The scorer link can enter scores, set doubles pairings and reset matches — treat it like a key and only give it to the person scoring. The spectator link is view-only and safe to share with everyone.

How do I set the doubles pairings?

Once all singles are finished, the "Set up Doubles Pairings" panel appears automatically on the scorer's match day page. Pick the players for each doubles and hit Create Doubles. Afterwards the panel closes; a small Edit Doubles Pairings button remains in the Doubles section until the first doubles match starts.

A doubles match already started — how do I fix a wrong pairing?

Pairings lock as soon as a doubles match starts, so the edit button disappears. To change the names anyway:

  1. Open that doubles match from the match day page (as scorer).
  2. Press Reset — this clears that match's score (only that one match).
  3. Back on the match day page, the Edit Doubles Pairings button is available again. Fix the names and save.
  4. Re-enter the points that had been played, if any.

Note: Reset really deletes that match's score — that's why changing a running pairing is deliberately not a one-click action.

I scored a point for the wrong player — what now?

Tap Undo on the match page. It takes back the last action (point or game), one step at a time, and also rolls back the per-point statistics.

A match wasn't scored live — can I enter the final result?

Yes. On the scorer's match day page every match card has an Enter Score button where you type the set results directly (e.g. 6:4, 3:6, 10:7).

What are the per-point tags (Ace, Winner, …)?

After each point the scorer can optionally tag how it ended — Ace, Winner, Unforced Error, Forced Error or Double Fault. The tags feed the statistics panel. Tagging is optional and can be skipped; the sheet closes by itself. Spectators see the statistics once the match is finished.

Do I need an account?

Only for creating match days. Register at /register, then use "New Match Day" in your dashboard. Scoring and watching work purely with the shared links.

Where do the club players and LK values come from?

From the WTB website. When creating a match day, search for a club and its player list (with Rang and LK) loads automatically. Player data refreshes when it's older than a week; an admin can also trigger a sync manually.
